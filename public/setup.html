Location (weather)

Forecasts come from Open-Meteo, which serves Met Office model data (the 2 km UKV model over the UK). Free, no key.

Calendars

Google: Calendar on the web, Settings, pick the calendar, Integrate calendar, copy Secret address in iCal format. Google refreshes these feeds slowly, so new events can take a few hours to appear.
Outlook / Microsoft 365: Settings, Calendar, Shared calendars, Publish a calendar, choose it, publish, copy the ICS link. Some work accounts block publishing.
Treat these links like passwords: anyone with one can read that calendar.

Todoist

Get it in Todoist: Settings, Integrations, Developer, copy the API token. It stays on the Pi.

Alarm volume

The sound is a slow, soft chime that fades in over about 90 seconds. It plays through the Pi’s audio output, so set the level once with Test.

API token (optional)

iOS Shortcut: add a Get Contents of URL action. URL , method POST, request body JSON with a text field wake. For its value, use Format Date on the wake-up date and choose ISO 8601 with the time included. Apple’s docs show this as 2016-06-01T14:41:36-08:00, offset included. Plain 07:00 also works (next 7am). Add "alarm": false to skip tomorrow’s alarm. /api/wake wakes it early. With a token set, send header Authorization: Bearer <token>.
